# PM 발표 준비 러닝 노트

> 이 문서는 완성된 발표 대본이 아니라, 개발 과정에서 발표에 쓸 근거와 사례를 계속 모으는 재료 창고입니다.
> 확인된 사실만 적고, 기억에 의존하거나 팀 확인이 필요한 내용은 반드시 `❓ 확인 필요`로 표시합니다.

## 사용법

- 개발 중 의미 있는 결정·변경·문제가 생기면 해당 항목에 2~5줄로 기록합니다.
- 가능한 경우 날짜, 담당자, 회의록·이슈·PR·커밋·화면 캡처 등 근거를 함께 남깁니다.
- 기능 목록보다 **왜 결정했는지**, **무엇이 바뀌었는지**, **결과가 어땠는지**를 우선 기록합니다.
- 발표 직전에는 `🎤 발표 후보`만 추려 PPT와 발표 대본으로 옮깁니다.

### 태그

- `🎤 발표 후보`: 발표에서 직접 설명할 만한 핵심 내용
- `📌 참고`: 발표 질문 대응이나 보충 설명에 쓸 내용
- `❓ 확인 필요`: 팀원·문서·데이터로 사실 확인이 필요한 내용
- `🧾 근거`: 회의록, 문서, 이슈, PR, 커밋, 캡처, 수치 등의 위치
