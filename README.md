# Pairing Admin Frontend

Pairing 서비스 운영을 위한 관리자 웹 프론트엔드입니다.

## 기술 스택

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- npm

## 시작하기

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 [http://localhost:3000](http://localhost:3000)에서 실행됩니다.

## 명령어

```bash
npm run dev      # 개발 서버
npm run lint     # ESLint 검사
npm run build    # 프로덕션 빌드
npm run start    # 프로덕션 서버
```

현재 테스트 도구와 테스트 스크립트는 도입되지 않았습니다.
